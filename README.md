# Адуучин тэмцээн — оролцогчийн бүртгэл

Нэг хуудастай бүртгэлийн форм (`index.html`) → Supabase (`registrations` хүснэгт). GitHub Pages дээр байрлана.

## Тохируулах
1. Supabase төсөл үүсгээд `supabase.sql`-ийг SQL Editor дээр ажиллуул.
2. `index.html` дотор `SUPABASE_URL`, `SUPABASE_KEY` (publishable/anon key)-г солино.
3. GitHub → Settings → Pages → Branch: `main` / root.
4. Хаяг: https://moriton-tech.github.io/Aduuchin/ (QR: `qr.png`)

Дата зөвхөн Supabase Dashboard (Table Editor) эсвэл service key-ээр уншигдана; формоос унших боломжгүй (RLS).
